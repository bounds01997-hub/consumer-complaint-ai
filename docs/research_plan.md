# 第一阶段研究计划

## 目标与待确认事项

围绕投诉文本分类与多维语义分析，建立可复核、可比较、可追溯的研究流程。当前交付是目录骨架与公开模板，没有实际模型或实验结果。

开始业务实现前，由用户在授权环境内确认：

- 六层体系原始文件的授权范围、版本、六层名称及定义；各层是否多标签、是否存在依赖或层级约束。
- A/B/C 的业务含义、输入输出和与六层体系的关系。A/B/C 不是本仓库自行定义的标签枚举，也不对应三条实验路线。
- 多维分析的维度、允许输出的取值、缺失和不确定情况的处理方式。
- 可使用的数据、人工标注与复核规范，以及是否允许向指定模型服务传输数据。

实际标准与映射由用户合规授权后本地维护；公共模板中不填真实内容。

## 拟议实验设计（尚未实现）

| 路线 | 比较内容 | 前置条件 |
| --- | --- | --- |
| `baseline_svm` | 文本特征与 SVM 分类基线 | 已确认任务定义和授权标注数据 |
| `baseline_llm` | 固定提示词的直接 LLM 分类 | 已确认模型调用与数据传输授权 |
| `rules_llm` | 六层标准约束下的 LLM 输出 | 已授权的本地规则及可追溯的规则版本 |

三条路线共用任务定义和固定的评估划分。先按投诉记录及近重复文本分组，再划分训练、验证和测试数据；特征拟合仅使用训练集。测试集不得用于调参或修改提示词。

待任务定义明确后选择宏平均 F1、每类精确率与召回率；若为多标签任务再确定适配指标。同时观察格式合格率、规则一致性、待复核比例，以及模型调用成本与耗时。不预设准确率承诺或验收阈值。

## 人工复核与可追溯性

规则冲突、无匹配、无效输出或不确定结果应转人工复核。模型自行给出的置信度不可直接当作经过校准的概率。

实验记录至少保留代码提交、业务标准版本、模板版本、数据划分标识、随机种子、模型及提示词版本、指标与复核结论。真实记录、明细输出和含案例的提示词均仅存放本地；公开报告需另行确认可公开范围。

## 范围限制

第一阶段不实现 RAG、Agent、模型微调、业务证据核验，也不作责任认定、自动处置或生产部署。文本归因仅是候选解释，不等于真实原因已被验证。
