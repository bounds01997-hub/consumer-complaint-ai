# 路线图

## 阶段 0：仓库初始化（本次交付）

- 中文说明、研究边界、目录职责与安全约定。
- 六层结构与分类规则空模板。
- 五个核心模块、三条实验路线、测试、界面与脚本目录占位。
- 轻量配置依赖及无密钥的环境变量示例。

本阶段不含业务算法、模型调用、测试用例或可运行界面。

## 阶段 1：业务确认与基础实验（待开展）

1. 用户确认六层标准、A/B/C 定义、数据使用范围和人工标注规范。
2. 在授权环境中本地维护标准与映射，约定数据输入和结果格式。
3. 逐步实现预处理、输出校验和人工复核记录，并使用合成样例编写测试。
4. 在相同任务与划分上分别实现 SVM、直接 LLM、规则约束 LLM 对照实验。
5. 评估错误类型、复核负担和资源消耗；形成经审查可公开的研究结论。
6. 有稳定流程后再实现本地 Streamlit 研究界面。

本阶段明确排除 RAG、Agent、模型微调和业务证据核验。进度取决于授权、标准确认和评估结果，不预设完成日期或模型效果。

## 后续阶段

当前不承诺更复杂的技术路线。新增能力须另行明确需求、数据授权、评估依据与边界，再制定实现计划。
