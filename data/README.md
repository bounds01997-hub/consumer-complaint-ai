# 本地数据管理

**真实投诉数据不入库。** 本目录仅允许跟踪本说明文件，其余内容由根目录 `.gitignore` 排除。

不得提交原始投诉文本、脱敏后的真实样本、标注及复核结果、客户信息、附件、录音、截图、模型请求响应或包含真实案例的提示词。脱敏不意味着可以公开。

合规授权后的本地目录可按需创建，例如 `data/raw/`、`data/processed/`、`data/annotations/`，无需把真实内容或这些目录上传 GitHub。业务标准原始文件优先放在仓库外的受控位置；实际标签字典和映射可放在被忽略的 `rules/local/`。输出明细和模型产物放在被忽略的 `outputs/`。

六层体系是业务标准，真实内容由用户依据授权原始文件维护。公开的 `rules/` YAML 仅为空结构模板，不得把本地标准复制回公开模板。

如需公共样例，应单独人工构造、确认不含真实业务或个人信息，并在提交前审查。真实数据即使改名、转换格式或移动目录也不能公开。

`.gitignore` 不是访问控制或敏感信息检测工具，不能阻止强制添加，也不能移除 Git 已追踪的内容。提交前查看 `git status` 与 `git diff --cached`；本地敏感文件需另行做好权限管理和备份。不得在 Issues、PR、截图或日志中泄露。
